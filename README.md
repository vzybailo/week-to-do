Weekly Tasks App is a full-stack web application that helps users plan, organize, and track their weekly tasks.
It’s designed to provide a clean, intuitive interface for managing daily goals and keeping productivity on track.

This project demonstrates how to build a complete modern web app using React + TypeScript on the frontend and Node.js + Express + MongoDB on the backend.
It includes authentication, RESTful API design, state management, and a responsive UI.

✨ Features

🗓️ Create, edit, and delete weekly tasks

👤 User authentication and session handling

💾 Persistent data storage in MongoDB

⚙️ REST API built with Express

🎨 Responsive UI built with Tailwind CSS

🧠 Global state management with Redux Toolkit

🚀 Full TypeScript support (frontend & backend)

🧰 Tech Stack

Frontend: React, TypeScript, Redux Toolkit, Tailwind CSS
Backend: Node.js, Express, MongoDB (Mongoose)

🎯 Project Goals

Showcase a full-stack architecture for a real-world productivity app

Demonstrate TypeScript best practices in both client and server code

Practice authentication, API design, and modular code organization
